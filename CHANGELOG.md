# Changelog

All notable changes to OpenConsent EU will be documented here.

## [Unreleased]

- 1.1.0 work is in progress and has not been released.
- Added a top-level OpenConsent EU admin menu and page-scoped admin styling.
- Added configurable EU privacy-rights resources and optional neutral project attribution in the preference dialog.
- Improved consent transitions, reduced-motion behavior, keyboard focus handling, script activation ordering, and consent invalidation when categories or script mappings change.
- Added PHP settings and headless-browser test harnesses.
- Hardened dialog fallback closing, reliable focus restoration, and queued script activation timeouts.
- Prevented administrators from disabling a category while it still has configured script mappings.

## [1.0.0] - Initial Release

- Added configurable consent banner, category preferences, browser-local choice expiry and versioning, and consent withdrawal.
- Added settings for category purposes, appearance, and explicitly mapped WordPress scripts.
- Added light, dark, and device-based themes with configurable colors and typography.
- Added optional Google Consent Mode v2 signals.
- Added GitHub release update checking.
