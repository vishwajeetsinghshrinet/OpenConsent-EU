# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OpenConsent EU, please report it privately to the project maintainer.

Please do not publicly disclose the vulnerability until it has been reviewed and addressed.

Include:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected version
* Any relevant screenshots or technical details

## Security Updates

Security fixes will be released through the official OpenConsent EU GitHub repository.

Users should keep OpenConsent EU updated to the latest stable release.
